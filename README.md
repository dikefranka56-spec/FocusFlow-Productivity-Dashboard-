# FocusFlow — Productivity Dashboard

A responsive productivity dashboard built with HTML, CSS, and vanilla JavaScript.

## Features
- Add, complete, search, and clear tasks
- Task priority labels and live completion statistics
- Browser-local task persistence with `localStorage`
- Focus timer and current-week overview
- Responsive dashboard layout

## Run
Open `index.html` in a modern browser. No dependencies or build tools required.

## Data note
Tasks are stored locally in the current browser only. They are not synced to a server. Avoid entering confidential information.
